# VidGravity P173 / P174 integration
P173 ports the reviewed social-export/player UI into root PWA, Cloudflare site, and Capacitor web source paths. It adds a bounded FFmpeg export route and SHA-256 headers for completed downloads.
P174 adds native Android text/plain share intake, encrypted preferences, automatic or interactive quality selection, WorkManager progress/cancel controls, checksum verification before MediaStore publication, and SQLite library indexing. Provider availability and access controls remain authoritative. Build and test on a real Android device before release.
