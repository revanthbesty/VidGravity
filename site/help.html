Step-by-step

How-to guides

How do I download media?
  1. Open Home and paste a complete URL from a supported source.
  2. Select Inspect/Analyze and review the formats reported by the source.
  3. Choose a listed quality or audio-only format. A missing resolution cannot be created by choosing a label.
  4. Start the download and monitor its state in Downloads.
  5. After success, open Library and confirm the file appears and plays.

If analysis fails, check the URL, internet access, source availability, and displayed error.

What if a download is stuck or shows no progress?
  1. Check whether the job is queued, running, paused, blocked, or failed.
  2. Confirm internet access and any unmetered-network requirement.
  3. Wait briefly during source analysis; progress may wait for provider status.
  4. If failed, read the error details and retry if offered.
  5. If it repeats, record the exact error, platform/build, and time. Never include secrets.
Why is my preferred resolution missing?

The quality picker depends on formats reported by the source and supported by the service. Some sources offer only a few resolutions; high-resolution video may require separate audio/video streams. Choose an available option or try another supported source.

Why is a completed download missing from Library?
  1. Confirm Downloads says succeeded, not queued or running.
  2. Refresh or reopen Library.
  3. Remember that browser/PWA storage and Android app storage may be separate.
  4. If still missing, capture the job status and error for support.
Why won't a saved file play?

Check that the download is complete and has a non-zero size. Reopen it and retry if incomplete. Codec/container support depends on the platform's player.

Network or service unavailable
  1. Check your connection.
  2. Retry once after confirming service reachability.
  3. If persistent, note the timestamp, platform/build, and exact error.
  4. Never share API keys, tokens, cookies, or private signed URLs.
Checksum verification failed or media was not published

The file failed integrity verification or the required checksum receipt was missing. Do not treat an unverified file as successfully published. Retry; report the exact error if it repeats.

Android background download or notification issue

Check notification permission, connectivity, and battery/background restrictions. If a foreground-service error appears, record the Android version and exact message. Device vendors may handle background work differently.

Why is a creator feature unavailable?

Some editing, enhancement, or audio functions require a native media engine or platform capability. Treat a feature marked unavailable as not active in that build, not as a successful operation.

Quick answers

Frequently asked questions

Does Best available always mean 8K?

No. It means the best compatible option reported by the source and service.

Are web and Android libraries automatically synchronized?

Not necessarily. Browser and native app storage are separate unless a documented sync feature connects them.

Can I download any URL?

No. Support depends on the source, permissions, service capabilities, and applicable terms and laws. Save only content you are authorized to download.

What should I include in a bug report?

Include platform/build, device/OS if relevant, steps, expected vs actual behavior, and exact error. Remove credentials, cookies, tokens, and private URLs.
