▶ MediaDock

Privacy Policy

For MediaDock — Video & Audio Saver, browser-only Chrome/Edge extension. Local-first media detection and downloads, without an account or Windows companion.

Effective 25 October 2026 · Extension version 2.4.1

Privacy at a glance

MediaDock detects compatible media and lets you choose downloads. The inspected v2.4.1 browser-only edition does not require a login, upload download history to a MediaDock-operated server, or contain a MediaDock-operated analytics tracker. Media downloads involve requests to the original website or media host.

Information accessed

To detect supported media, MediaDock may process the active webpage URL and title, HTML video/audio players, media resource URLs and filenames, network request metadata such as media content types, available source formats, and compatible playlist contents. Its content scripts and HTTP/HTTPS host permissions can operate across websites, including accessible embedded frames. MediaDock does not intentionally read passwords or payment details.

When enabled, MediaDock also processes recent download filenames, download IDs and statuses. It stores appearance, notification, filename, download and automation preferences.

How this information is used

Information is used to show compatible media options, associate media with the correct page or player, prevent duplicate/stale listings, show available source quality without inventing resolutions, suggest filenames, carry out downloads you select, and display optional download activity/completion information.

Storage and retention

  • Browser local storage keeps settings and, when activity history is enabled, up to 30 recent download activity records; clear the history in Automation Center.
  • Browser session storage temporarily holds per-tab media detection results and stream job details.
  • Downloaded files are managed by the browser and your device; clearing MediaDock history does not delete downloaded files.
  • If you upgraded from an older personal edition, unused local helper details might remain in local browser storage. This browser-only edition does not use that helper. Browser extension controls can clear old extension data.

Network access and disclosure

When inspecting or saving compatible media, MediaDock can retrieve playlists, media files, or stream segments from the original website/media host. These destinations may receive standard request data, such as the requested URL, IP address and, where browser request rules permit, existing site cookies or credentials. Their own privacy policies apply. The v2.4.1 edition does not send your browsing activity or download history to a MediaDock-operated service, sell this information, or use it for targeted advertising.

Browser permissions

downloads saves selected files and tracks download status. storage stores local preferences and activity/state. tabs associates media with the correct page and clears stale results after navigation. webRequest observes media-related network request metadata. HTTP/HTTPS host access allows media detection and optional on-page prompts across supported sources.

Your choices

  • You initiate each download yourself; MediaDock does not automatically save files without your choice.
  • You can change themes, download prompts, filename options, activity logging and Automation Center switches.
  • You can pause optional suggestions, clear local activity records, restrict site access, disable or uninstall the extension in Chrome/Edge.

Limitations

This policy covers only the MediaDock v2.4.1 browser extension, not desktop products or old helper prototypes. MediaDock does not support YouTube downloads, encrypted/DRM-protected streams, or bypassing restrictions. Use only with media you own or are allowed to download.

Updates and contact

We will update this policy and its effective date if MediaDock's data handling changes. Publisher: RevCore Astra (Chrome Web Store publisher). For privacy inquiries, use the publisher's support contact displayed on MediaDock's Chrome Web Store listing. The publisher must configure and monitor that support contact before public release.
